## 🔭 研究方向

- **灵巧操作**：灵巧手控制、臂手协同操作与物理交互。
- **遥操作**：结合动作捕捉与机器人控制，开展人引导的操作与机器人数据采集。
- **灵巧手重定向**：基于 MANO 手部表征与运动学约束，将人手动作映射至机器人灵巧手。
- **VLA 后训练**：结合机器人数据，通过后训练使视觉–语言–动作模型适配操作任务。
