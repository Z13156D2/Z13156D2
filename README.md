## 🔭 Focus

- **Dexterous Hand Control**：灵巧手串口通信、角度与力参数调试、实时状态回读及动作序列测试。
- **Sensing & Signal Processing**：压力与环境数据采集、信号可视化、温度补偿示例与实验数据导出。
- **Ultrasound & Hand Pose**：关注前臂超声 RF 信号与连续三维手部姿态重建，并整理超声成像仿真脚本。
