## 🔭 Focus

- **Dexterous Manipulation** — Dexterous hand control and coordinated arm–hand manipulation for physical interaction.
- **Teleoperation** — Motion capture and robot control for human-guided manipulation and robotics data collection.
- **Hand Retargeting** — Mapping human hand motion to robotic hands with MANO-based representations and kinematic constraints.
- **VLA Post-Training** — Adapting vision-language-action models to manipulation tasks through post-training and robotics data.
